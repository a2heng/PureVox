# uitk 设计规范

适用范围：`uitk/` 全部组件与对话框。目标：视觉区域扁平（最多两层嵌套）、
对比度恒定、像素风格统一。改 UI 前先读此文件；新增颜色/字号必须先进
`theme.py` 令牌表，禁止在组件里写十六进制字面量。

## 1. 配色令牌（唯一来源 `theme.py`，星露谷浅色）

| 令牌 | 值 | 用途 |
|---|---|---|
| `WINDOW` | `#FFF8E1` | 窗底（羊皮纸） |
| `PANEL` | `#FFECB3` | 行/卡片面板 |
| `BASE` | `#FFFFFF` | 输入区、下拉弹层、图表画布（纯白） |
| `BUTTON` | `#FFB74D` | 主按钮 / 可点标签常态底 |
| `DARK` | `#FFE0B2` | 悬停变体（配 `theme.hover(bg)`） |
| `MID` | `#8D6E63` | 边框、分隔线、描边 |
| `TRACK` | `#E6C79A` | 滑杆槽 |
| `TITLE_BG` / `TITLE_FG` | `#6D4C41` / `#FFF8E1` | 标题栏（深棕锚点） |
| `TEXT` / `TEXT_DIM` / `TEXT_FAINT` | 深棕三档 | 主文字 / 次要 / 装饰 |
| `START_*` / `STOP_*` | 绿 / 红 | 启停状态 |
| `ACCENT` / `ACCENT_TEXT` | 橙 / 深棕 | 强调（选中态、手柄、曲线） |

**对比度铁律**：橙底上禁止橙字（用 `TEXT`）；深底（`TITLE_BG/STOP_BG`）
上用白或 `TITLE_FG`；白/浅黄底上用 `TEXT/TEXT_DIM`。

## 2. 视觉层级（最多两层）

```
WINDOW(窗底)
└─ PANEL(行卡片 / 对话框 body)          ← 第 1 层容器
   └─ BASE(输入框/下拉/画布) 或 控件     ← 第 2 层
```

- 禁止三层以上同色系互相嵌套（面板套面板套面板）。
- 容器之间靠 **底色差 + 1px `MID` 描边** 分隔，不引入阴影/渐变。
- 标题栏是唯一的深色块（锚点），其余全为暖浅色。

## 3. 字体与尺寸

- 全部来自 `metrics.make_sizes(zoom)` 尺寸表；负数字号 = 像素。
- Canvas 自绘元素（VU/频谱/EQ 曲线）的线宽、手柄、刻度字号一律
  `int(round(base * sizes["scale"]))` 随挡位缩放。
- 正文字号 `font_body`，次要 `font_small`；图表内刻度 ≥7px。

## 4. 组件约定

| 组件 | 规范 |
|---|---|
| VU 条 | 分段格子（马赛克 LED），单条高度，无外置刻度轴；峰值 dB 内嵌条右端；分区 绿<‑20<黄<‑9≤红 |
| 频谱 | 128 段 Mel，dB -90..-20，输出=绿基准柱、输入>输出=灰(残留)、输入<输出=浅(增强)；EMA α=0.3 |
| 下拉 | 弹层与外框严格同宽；行高 = combo_h；长项像素级省略「…」；滚轮一格一项 |
| 复选 | Canvas 正方形 + 直角对勾，勾选底=ACCENT、勾=ACCENT_TEXT |
| 按钮 | FlatButton：常态 BUTTON/BASE，悬停 hover()，主行动作才用状态色底 |
| 行布局 | `[手柄][开关][名称] ····· 用户操作区 ····· [×]`；类型名不占横向空间 |

## 5. 交互反馈

- 悬停必变色（`hover()`），可点击元素 `cursor="hand2"`。
- 参数滑杆实时下发引擎（拖动即生效），松手才持久化。
- 结构变更（增删/排序/开关）：运行中热重建一次，不逐帧重启。
