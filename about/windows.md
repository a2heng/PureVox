# PureVox 使用说明（Windows）

## 软件简介

PureVox 是一款 AI 麦克风降噪工具，能实时消除键盘声、鼠标声、电流声、风扇声、风声等背景噪音，只保留纯净人声。

## 快速开始（本地降噪）

### 第 1 步：启动软件

双击 PureVox.exe 打开软件。

界面是「节点面板」：默认已有 **录音输入 → AI 降噪 → 音频输出 → VU 电平表 → 频谱图** 五行。

如果检测到未安装 VB-CABLE，**音频输出**行内会显示状态卡，含下载地址与安装说明。

> **也可以手动安装 VB-CABLE：**
>
> 1. 到 VB-Audio 官网 https://vb-audio.com/Cable/ 下载 VB-CABLE 驱动
> 2. 右键 VBCABLE_Setup_x64.exe → **以管理员身份运行**
> 3. 点击安装按钮，安装完成后重启电脑
>
> PureVox 不随安装包内置第三方工具，检测到未安装时会给出下载地址。

### 第 2 步：设置系统声音

打开软件 **设置 ▾ → 系统声音** 打开声音控制面板。

**播放选项卡（CABLE Input）**

1. 右键你的实际扬声器/耳机 → **设置为默认设备**
   （注意：不设置的话系统音频可能无法正常从扬声器播放。）
2. 右键 **CABLE Input** → **属性** → **高级** → 格式设为 1 通道，16 位，48000 Hz

**录制选项卡（虚拟麦克风）**

1. 右键 **CABLE Output** → **设置为默认设备**
   （注意：必须设置，否则降噪后的麦克风在其他软件中无法使用。）
2. 右键 **CABLE Output** → **属性** → **高级** → 格式设为 1 通道，16 位，48000 Hz

> **采样率全自动适配：**输入/输出设备任意采样率均可直接使用，无需手动设置，
> 更不会弹框阻止。状态栏会显示如「输入：2ch 44100Hz → 48kHz（自适应重采样）」
> 或「输出：2ch 48kHz → 44100Hz（自适应重采样）」，48kHz 设备显示直通。

### 第 3 步：选择设备

1. **录音输入**：行内下拉选你的物理麦克风（耳机麦克风、桌面麦克风等）
2. **音频输出**：选 **CABLE Input**。它对应系统声音里的播放选项卡，降噪后的音频从录制选项卡的 CABLE Output 作为虚拟麦克风供其他软件使用。（注意：不要选你的扬声器/耳机，否则声音会直接外放，虚拟麦克风（CABLE Output）也收不到信号。）
3. **想监听**：点 **添加 ▾ → 设备 → 音频输出** 再加一路，选耳机/扬声器即可实时听到降噪效果
4. **采样率**：不用手设，PureVox 一律按 F32 单声道 48kHz 处理

### 第 4 步：开始降噪

点击 **启动音频处理** 按钮，按钮变红即表示降噪已开启。

这时候打开微信、Discord、游戏等软件，把麦克风设为 **CABLE Output** 或 **默认麦克风**，对方听到的就是降噪后的声音了。

## 处理链与节点

所有处理都以「节点」形式存在：用 **添加 ▾** 增加，拖拽行首手柄排序，点行尾 × 删除。

- **设备**：录音输入 / 网络输入 / 播放输入 / AEC 输入 / 音频输出
- **媒体输入**：音效板 / 音乐播放器 / 桌面声音输入
- **处理**：增益 / 自动增益 AGC / 噪声门 VAD / 均衡器 EQ（10·31·61 段）/ 压缩器 / AI 降噪 / 目标说话人 TSE
- **可视化**：VU 电平表 / 频谱图

默认链已含 **AI 降噪**，日常直接启动即可。

- **回声消除**：**添加 ▾ → 设备 → AEC 输入**，行内选好麦克风与 far 参考源（扬声器/另一路麦克风二选一）。
- **目标说话人提取**：添加 **目标说话人 TSE** 节点，先在它行内点开录制一段参考语音，再启用即只保留该人的声音。

## 增益设置

- **前增益**：麦克风输入音量。正常说话时 VU 表峰值在 **-12 ~ -6 dB** 为最佳
- **AGC**：自动调节增益，声音始终稳定。**建议开启**，开启后前增益滑块会自动被接管
- **VAD（噪声门）**：不说话时自动静音，消除残留底噪。**建议开启**

## VU 电平表

实时显示当前音量：

- 绿色（-60 ~ -18 dB）：音量正常
- 黄色（-18 ~ -6 dB）：声音够大
- 红色（-6 ~ 0 dB）：接近过载，建议降低增益

红色小点表示最近 10 秒内的峰值。

## 均衡器（EQ）

在 **均衡器 EQ** 节点行内点 **均衡器编辑**，打开曲线编辑器（10 / 31 / 61 段可选）。

可以直接拖动频点调节，也可以使用预设：

> 清晰透亮 · 温暖饱满 · 低沉有力 · 减少齿音 · 减少鼻音 · 消除沉闷 · 增强临场

## 远程麦克风（手机无线麦克风）

用手机当无线麦克风，音频通过局域网推流到电脑进行降噪，降噪后仍然通过 VB-Cable 输出给其他软件（或从你选的输出设备播放）。

### 准备工作

确保电脑和手机在 **同一个局域网**（连同一个 WiFi）。

### 操作步骤

1. 点 **添加 ▾ → 设备 → 网络输入**，新增一个网络输入行
2. 在行内选择网卡（IP），右侧会显示二维码与监听地址（如 https://192.168.1.100:59123，自动生成，一般不用改）
3. 点击 **启动音频处理**，电脑开始等待手机连接
   （注意：首次使用时会弹出防火墙授权提示，点击 **是** 即可，后续启动不会再弹出）

**浏览器访问（推荐）**

1. 手机扫码，或浏览器打开电脑上显示的网址（如 https://192.168.1.100:59123 ）
2. 首次访问浏览器会提示"不安全"，（注意：点击 **高级 → 继续访问** 即可，自签名证书，连接加密，安全）
3. 点击页面上的麦克风按钮，开始说话，电脑端就会收到并降噪

**Android App**

1. 安装发布页的 **PureVox-Android-arm64-\<日期\>-debug.apk** 到手机
2. 打开 App，会自动搜索局域网内的 PureVox 服务器
3. 搜到后自动连接，自动开始推流，无需任何操作

### 音频输出怎么选

远程麦克风模式下，降噪后的音频仍然会输出到你选的输出设备：

- 选 **CABLE Input** → 输出到虚拟麦克风（CABLE Output），供电脑上的软件使用（微信、游戏等）
- 选你的 **耳机/音箱** → 直接从扬声器听到手机端的声音

> 跟本地模式一样，输出设备继续选 **CABLE Input** 即可。

## 托盘图标

关闭主窗（或点托盘图标）会收进托盘，图标颜色即运行状态：

- **蓝色** = 音频处理运行中；**红色** = 已停止

左键点图标切换主窗显隐；右键菜单可「打开 PureVox / 启动（或停止）音频处理 / 退出」。

## 全局快捷键与提示音

在 **设置 → 快捷键与提示音** 中配置，全部可自定义、可留空：

设置弹窗只有两行，每行前面都是**开关复选框**：

- **启停快捷键**：默认 **右 Alt + .**（右 Alt + 句号键）；点方框后按下组合键即
  录制，Delete 清除（清空 = 不监听）。取消勾选 = 不监听。
- **启停提示音**：勾选后启停会响；点「启动提示音 / 停止提示音」两个按钮即时
  试听（启动音上行、停止音下行，成对设计）。提示音送到**系统默认输出设备**，
  与音频处理选用的输出设备无关——即使输出选了虚拟声卡，也能从扬声器听到。
- **音效板快捷键不在此弹窗**：就在音效行内直接录制（见「音效板」节点说明）。

## 数据目录

配置、日志、录音文件均保存在 ~/.purevox/ （如 C:\Users\用户名\.purevox\ ）。

- **音效板/音乐播放器**导入的文件会统一归一为 48kHz 单声道 WAV 入库，分开存放：
  `~/.purevox/soundpad/` 与 `~/.purevox/music/`；之后播放只读库内文件，
  原始文件移动/删除都不影响。

## 常见问题

**Q：别人听不到我的声音？**

检查：① 软件输出设备是否选了 **CABLE Input** ② 系统默认麦克风是否设为 **CABLE Output** ③ 软件是否点击了 **启动**

**Q：启动后没声音？**

检查：① 麦克风是否被系统独占 ② 输出设备是否选了 **CABLE Input** ③ 系统默认麦克风是否设为 **CABLE Output** ④ 是否弹出过 48kHz 弹框（见第 2 步说明）

**Q：降噪后人声变怪？**

先重置 **EQ**，然后调整前增益，确保说话时 VU 表不超过黄色区。

**Q：如何开机自启？**

**设置 ▾ → 开机自启** 打钩，下次开机 PureVox 会自动启动。

**Q：如何让软件启动后自动开始降噪？**

**设置 ▾ → 启动时自动运行** 打钩，软件打开后会自动开始降噪。可以配合开机自启一起使用。

**Q：手机连不上电脑？**

检查：① 手机和电脑是否 **同一 WiFi** ② 电脑防火墙是否拦截了 **59123 端口**（软件会自动添加规则，需要管理员权限）③ 网址是否输入正确
